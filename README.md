# 穷举之神 · Random Gods — ASCII Iterator Core

一台会**开机、失败、自我怀疑、疯狂运算、最终腐化断电**的巨型生物计算机，用 **128×58 的纯 ASCII 字符网格**实时渲染的音乐可视化 / 生成艺术短片。

配乐为 Rain World《Random Gods (Theme III)》(James Primate)。"Random Gods" 在这里被译作**穷举之神**——迭代器面对无解的终极问题，只能以必死的决心穷举一切可能。

## 叙事分镜（对齐音乐幕结构，199.3s）

| 幕 | 时间 | 内容 |
|----|------|------|
| ① 苏醒 POWER-ON | 0–22s | 系统级冷启动全景：⊗ 位圆形加载环、模块分三批上电、电流沿总线扩散、POST 自检、1MB 内存条（复位向量 0xFFFF0 / BIOS / 引导扇区 0x7C00） |
| ② 生物工程 | 22–39s | 顶部设备降下，对随机 DNA 片段做修改/替换/移位/拼接；右侧标本舱生成扭曲生体——**全部失败**，每次全屏闪红重试 |
| ②.5 自我怀疑 | 39–62s | 穷举尽墨，机器质疑自身：错误环 ⊗+X 移回画面中心，被噪声与故障淹没，再串行清屏重整旗鼓 |
| ③ 乱序运算高潮 | 62–146s | 事件驱动的乱序 CPU（5 级流水 / Cache+MESI / DRAM 状态机 / 中断仲裁 / 总线竞争），全宽 DNA 混乱重组，金色 ⊗ 计算之心，`TRIPLE AFFIRMATION` 块字进度条于 146s 填满 |
| 腐化 / 断电 | 146–199s | 答案即腐化：三重肯定变紫扭曲滴落，紫色黏液自心脏向外侵蚀各部件，POWER 最后倒下 → 黑屏死寂 |

## 技术要点

- **纯函数逐帧**：每帧 = f(tick)，无持久状态 → 可任意 seek、离线逐帧校核、帧率精确。
- **事件驱动微架构仿真**（`ascii/src/cpu.js`）：乱序发射、组相联 Cache、DRAM 命令状态机、中断优先级抢占——"繁忙"来自真实的资源竞争与状态变化，而非装饰动画。
- **多重异步时钟**：不同音频音色通道驱动各自的时钟域，永不对齐（呼应 Rain World 的 GALS 设定）。
- **统一符号语法**：地址=黄 / 数据=青 / 控制=红 / 中断=紫 / 时钟=白 / 腐化=紫黏液。
- **场景间组件 morph 过渡**（不淡黑）：① 内存条升起展开为 ② 的 DNA；① 的 CLK 线伸展为 LOGIC ANALYZER；①→② 用 1s 字符阵解码变换。
- **出片**：`tools/record_video.py` 无头逐帧截图 → ffmpeg 30fps 合成（本仓库不含音频与视频）。

## 本地运行

需要一个本地 HTTP 服务（`file://` 会拦下 `pack.json`）：

```bash
python tools/serve.py 8712
# 打开 http://127.0.0.1:8712/ascii/
```

把《Random Gods (Theme III)》的 mp3 放到 `resource/` 即可带声播放（因版权不随仓库分发）。
离线校核：`node ascii/check_cpu.js`。
